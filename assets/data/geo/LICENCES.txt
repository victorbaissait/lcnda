Fonds de carte des diagrammes « Cartes » (carte colorée par zones, carte des migrations)
=====================================================================================

Ces fichiers sont produits par scripts/build-geo-maps.js à partir des sources ci-dessous, téléchargées telles
quelles. Les tracés ont seulement été simplifiés (topojson-simplify) et quantifiés ; aucun contour n'a été
dessiné à la main. Les noms des zones sont en français (traductions ajoutées dans le script) ; les codes
d'origine (INSEE, NUTS, ISO 3166) sont gardés pour relier les lieux de l'application.
Chaque carte dessinée rappelle sa source en petit, en bas à droite (« Fond : … »), comme le demandent les licences.

3. eu-nuts1.json, eu-nuts2.json, be-provinces.json, be-regions.json, ch-cantons.json, ch-regions.json
----------------------------------------------------------------------------------------------------
Source : Eurostat GISCO, nomenclature NUTS version 2024 (régions NUTS 1, 2 et 3), échelles 1:10 000 000 et
1:3 000 000, servie en TopoJSON par Eurostat sur https://github.com/eurostat/Nuts2json (pub/v2/2024/4326/…).
Mention obligatoire, à montrer sur la carte : « © EuroGeographics for the administrative boundaries »
(sur les cartes de l'app : « Fond : © EuroGeographics (Eurostat GISCO) »).
Conditions : https://ec.europa.eu/eurostat/web/gisco/geodata/administrative-units — réutilisation autorisée
à condition de citer la source ; les conditions d'Eurostat GISCO réservent certains jeux de limites
administratives à un usage non commercial : l'application étant libre et gratuite (AGPL), cet usage est couvert ;
à revoir si LCNDA devait un jour être vendue.
Le code de Nuts2json est sous licence EUPL 1.2 (le code n'est pas repris, seulement les données).
Belgique : provinces = NUTS 2 (BE10…BE35), régions = NUTS 1 fondues depuis les provinces.
Suisse : cantons = NUTS 3 (CH011…CH070), grandes régions = NUTS 2. Noms français ajoutés dans le script.

📱 Le téléphone par le wifi : envoyer ses photos de terrain à l’ordinateur

Maquette à valider, rien n’est construit. Tu demandes : sur le même wifi que l’ordinateur, ton téléphone ouvre une page simple, prend ou choisit des photos (tombe, acte, plaque, maison), ajoute une ligne, et les envoie. Sur l’ordinateur, elles arrivent dans une boîte 📥 À trier où tu ranges chaque photo. Cette page montre ce qui existe déjà (lu dans le code), les écrans du téléphone, ceux de l’ordinateur, ce qui est sûr, les limites, et les réglages. Noms fictifs (Marie MAZAUD, Jean LACOMBE, Louise DURAND). Badges : nouveau fait évoluer l’existant existe. Cadres violets : chaque choix est un réglage, l’option conseillé d’abord, réglée au départ.

En deux mots. Le téléphone devient une boîte aux lettres : il peut glisser des photos par la fente, mais il ne peut ni ouvrir le carnet, ni rien y changer. C’est toi, sur l’ordinateur, qui ouvres la boîte et ranges chaque photo à sa place.

Ça passe par le wifi de la maison (jamais par internet), par la même porte que 🖧 Plusieurs ordinateurs, qui reste fermée tant que tu ne l’ouvres pas. Le téléphone est accepté une fois, en comparant un code à 6 chiffres, comme un autre ordinateur, mais avec un droit plus petit : 📱 Téléphone de terrain = déposer seulement.

Au cimetière sans wifi : la page garde les photos en attente tant qu’elle reste ouverte, et les envoie quand le téléphone retrouve le wifi de la maison. Ce n’est pas garanti à 100 % (voir les limites) : la visite par fichier reste là pour une journée entière aux archives.

7. Ce qui est sûr, et les limites

sûr ce que le téléphone ne peut pas faire

  • Rien sans ton accord : la porte est fermée au départ ; le téléphone est accepté sur l’ordinateur, code à 6 chiffres comparé.
  • Déposer seulement : une seule écriture permise (dans 📥 À trier) ; aucune fiche lue ni changée ; aucun export.
  • Liste réduite : nom, prénom, années ; jamais les vivants ni les fiches confidentielles (réglage) ; aucun lien vers les fiches.
  • Maison seulement : adresse privée du même wifi, jamais internet.
  • Retirer en un clic : le jeton est refusé tout de suite.
  • Tout est noté dans 📜 Qui a vu quoi.

vérifié ce qui arrive est contrôlé

  • Type réel : premiers octets du fichier comparés (JPEG, PNG, WEBP, AVIF) ; un PDF ou un fichier renommé est refusé.
  • Tailles : par photo, par envoi, et pour la boîte entière (voir Réglages · 8).
  • Noms tirés au hasard sur l’ordinateur ; le nom venu du téléphone n’est jamais un chemin.
  • Texte : une ligne, affichée comme du texte.
  • GPS retiré à l’arrivée par défaut (la photo est réenregistrée sans ses données cachées).
  • Hors de l’arbre tant que tu n’as pas relié.

limites à savoir

  • Pas de HTTPS (comme 🖧 Plusieurs ordinateurs) : les photos passent en clair dans le wifi ; il faut un wifi protégé par sa clé. Le navigateur affiche « Non sécurisé ».
  • Hors wifi : la page doit être ouverte avant de partir et rester ouverte ; le téléphone peut effacer les photos en attente. Pas de service worker sans HTTPS.
  • L’ordinateur doit être allumé, LCNDA ouvert, porte ouverte, pour recevoir.
  • Une seule généalogie : celle ouverte sur l’ordinateur.
  • Navigation privée ou données du navigateur effacées : le téléphone oublie son accès, il faut l’autoriser de nouveau.
  • Une journée aux archives sans wifi : utilise la visite par fichier.

Aujourd’hui, montrer 📄 Documents quand on fait sa généalogie est déjà possible (Réglages → Menus, colonne et listes → cocher la ligne), mais personne ne le sait. B2d’où ça vient · cas limites

Lu par l’index léger du tableau de bord, sans rien recopier

Aujourd’hui succ_index() lit, dans chaque généalogie, un petit résumé des dossiers (n°, titre, état, notaire, prochaine échéance, nombre en retard). On y ajoute, pour la cloche :

  • les échéances non faites dues aujourd’hui ou avant (et les 7 jours qui viennent, repliés) : date, texte, sorte ;
  • les relances des courriers reliés aux dossiers (courriers.succ_case_id, relance_date, réponse pas reçue) : n° du courrier et objet seulement ;
  • jamais le nom d’un héritier vivant ni une adresse (la règle de l’index reste vraie) : le nom se voit une fois le dossier ouvert.
Cas limites
  • Rien à faire : pas de pastille ; le panneau dit « ✓ Rien pour aujourd’hui. Prochaine : 24 nov. (2026-014) ».
  • Plus de 9 : « 9+ ». Les retards d’abord, puis le plus ancien.
  • Une généalogie illisible (fichier abîmé, autre version) : une ligne grise « ⚠️ ⚖️ 2026-016 : impossible de lire les échéances ».
  • ⏭ Reporter / ✓ Fait dans une autre généalogie : écrit dans celle-là (comme ⇄ Déplacer), avec ↶ Annuler ; note au journal du dossier.
  • Mise à jour : à l’ouverture de l’app, à minuit, et après chaque changement d’échéance — pas de lecture en boucle.
  • Mode consultation / mode simple : pas de cloche. Usage non successoral : pas de cloche.
Réutilise : succ_index_rows() (un champ due_items de plus), semaine_mark() pour ✓ / ⏭ quand c’est la base ouverte, le style des boutons TB_ITEMS.
Décisions à prendre · B2

B7. 🔐 Mot de passe sur une généalogie nouveau même méthode que le 🔒 mode consultation

B7ce que ça protège vraiment

Soyons honnêtes : un verrou d’écran n’est pas un coffre-fort

Aujourd’hui, rien n’est demandé pour ouvrir une généalogie. Le 🔒 mode consultation a un mot de passe, mais seulement pour en sortir, et il laisse tout lire. Le fichier de la base (SQLite) n’est pas chiffré : qui copie le dossier de l’app peut le lire avec un autre logiciel. Les sauvegardes, elles, peuvent déjà être protégées (AES-256).

📊 31 diagrammes proposés : l’audit des doublons, puis la maquette

Chaque proposition a été cherchée dans le code (types de diagrammes, vues de Graphiques, arbre décoratif, outils de la Carte, ADN, successions, preuves, options communes, FAQ). Doublon = ça existe déjà, on ne le refait pas. Option = presque là : on l’ajoute comme réglage d’un type existant, pas comme un type de plus. Nouveau = rien d’équivalent. Toutes les personnes et tous les lieux des dessins sont inventés.

🔎 Grand audit des onglets : ce qu'on peut ajouter, ce qu'on peut harmoniser

Chaque onglet du menu regardé dans le code : ce qu'il fait déjà, ce qu'on peut y ajouter (de vraies fonctions dans l'onglet, pas un bouton qui renvoie ailleurs ; chaque idée vérifiée : elle n'existe pas encore) et ce qu'on peut harmoniser entre les onglets. Rien n'est codé : dis-moi ce que tu prends.

En bref. Les onglets récents (Successions, Suivi, Documents, Catalogue) suivent déjà les règles communes ; les onglets d'origine (Enquêtes, Chronologie, Comparaison, Recherche, Réglages, ADN) sont en retard.

Les ajouts qui rapportent le plus : une vraie liste des Sources (fusion, dépôts, « où est-elle citée ») ; « Ton lien avec cette personne » sur la fiche ; chercher et remplacer dans les données (prénoms, métiers, lieux) ; fusionner depuis la Comparaison ; filtres de lignée sur la Carte ; fiche familiale imprimable ; événement confidentiel ; arbre en grand format découpé en feuilles A4 ; un historique de tous les « ↶ Annuler ».

À harmoniser d'abord : « ↶ Annuler » au lieu de « Es-tu sûr ? » (Enquêtes, ADN, Recherche) ; rien de modifiable en mode consultation ; la même barre « Chercher · Filtrer · Trier » dans chaque colonne ; Exporter / Imprimer et raccourcis clavier partout ; tes réglages gardés quand tu changes d'ordinateur (147 réglages ne le sont pas aujourd'hui).

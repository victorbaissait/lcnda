📜 Atelier de transcription : versions, mots sur l'image, et « Aider l'IA »

Maquette à valider avant de coder. Elle reprend l'Atelier tel qu'il est (image à gauche avec les bandes de couleur des lignes, texte à droite avec les lignes numérotées de la même couleur, étapes Lire · Corriger · Repérer · Ajouter). Noms inventés (MAZAUD, LACOMBE, DURAND).

En bref, quatre ajouts :

🕘 Les versions, en un coup d'œil — une petite bande de pastilles juste au-dessus de « 📄 Ce texte est celui du document… » : ma version, chaque lecture de l'IA (modèle, date, image utilisée), une copie. Un clic pour la voir, « Utiliser » ou « Comparer ».

🔦 Les mots sur l'image — je sélectionne un ou plusieurs mots : un petit cadre les montre à l'intérieur de la bande de la ligne.

🧠 Aider l'IA — le titre, une phrase pour dire de quoi parle l'acte, les personnes déjà reliées et ce que la base sait d'elles : l'IA s'en sert pour lire les mots douteux, sans rien inventer.

❓ Pourquoi cet acte a été fait — pour un acte de notoriété : prouver le célibat avant un mariage, remplacer un acte de naissance perdu, succession, pension…

🕘 La bande « Versions » nouveau

Une pastille par version gardée. Ma version est toujours la première : c'est le texte du document. Un clic sur une autre pastille l'affiche en lecture seule, sous la bande (cadre violet), avec :

✓ Utiliser cette version⚖️ Comparer× Fermer

Utiliser met ce texte dans « Ma version » (l'ancien est gardé, ↶ possible). Comparer ouvre la fenêtre déjà là « ⚖️ Comparer les lectures », mot par mot, avec ces deux versions cochées.

⧉ Dupliquer garde une copie de la version affichée : on garde ce que l'IA a lu, puis on corrige tranquillement. La copie s'appelle « 📋 Copie de l'IA » (renommable).

Les lectures sont déjà gardées aujourd'hui (« Garder chaque nouvelle lecture (écriture à la main, IA, OCR) », allumé de départ ; fenêtre « 🕘 Versions » ; act_transcription_versions avec source et le modèle). La bande ne fait que les montrer là où l'on travaille. Les versions automatiques (« Avant Tout remplacer »…) restent dans « ⋯ autres ».

Le modèle et l'image envoyée sont déjà connus au moment de la lecture (« Image envoyée : améliorée automatiquement »…) ; il suffit de les écrire avec la version. Survol d'une pastille = ces lignes en bulle.

🔦 Sélectionner des mots → les voir sur l'image nouveau

Aujourd'hui, la ligne du curseur est déjà mise en avant sur l'image (bande plus marquée). En plus : dès qu'on sélectionne un ou plusieurs mots, un cadre bleu plus serré les montre dans la bande. Sur plusieurs lignes : un cadre par ligne.

Comment l'app trouve la place : la bande de la ligne est connue ; les mots sont placés selon leur rang et leur longueur dans la ligne. C'est une estimation (le signe ≈). Si l'IA a renvoyé la place de chaque mot, le cadre est exact.

Marche aussi dans l'autre sens : clic sur l'image dans une bande → le curseur va sur le mot le plus proche de la ligne.

Sur téléphone

La bande « Versions » passe à la ligne, les pastilles gardent seulement l'icône et le nom court (« 🤖 Qwen3-VL »), le détail est dans l'aperçu. Le cadre des mots se voit dans l'onglet 🖼️ Image (un point bleu sur l'onglet le signale).

À décider

Questions

1. Quelles versions montrer dans la bande ?

A. Ma version + les lectures (IA, écriture à la main, OCR) + les copies ; les automatiques dans « ⋯ autres ».
B. Toutes les versions, automatiques comprises.
C. Seulement les 3 dernières, le reste dans « 🕘 Versions ».
Conseillé : A (la bande reste courte, rien n'est perdu).

2. Les indices de « Aider l'IA » : cochés au départ ?

A. Oui pour les noms, lieux et l'événement principal ; non pour le reste.
B. Tous décochés : on choisit soi-même.
C. Tous cochés.
Conseillé : A (aide utile sans trop guider l'IA).

3. « Utiliser cette version » : remplacer ou fusionner ?

A. Remplacer « Ma version » (l'ancienne est gardée, ↶).
B. Toujours passer par « ⚖️ Comparer » pour choisir mot par mot.
Conseillé : A, avec « ⚖️ Comparer » juste à côté.

4. Où écrire le « Pourquoi cet acte » sur la fiche ?

A. Sous l'événement « Acte de notoriété » de la chronologie.
B. Aussi dans la note de l'événement lié (le mariage).
Conseillé : A ; B en option.

# 🌐 Glossaire commun des traductions

À suivre pour toute traduction de LCNDA (mode d’emploi : `docs/I18N.md`). Un mot de l’app se traduit **toujours de la
même façon** dans une langue. Ton : on tutoie partout (en : *you* ; es : *tú* ; de : *du* ; it : *tu* ; pt : *tu* ;
pl : *ty* ; nl : *je*). Phrases courtes et simples, comme en français.

## Règles de forme

- Les symboles de tête validés (K11 : ＋ ↶ ↷ ⤒ ⤓ 💾 🖨 ✎ 🗑 × ↗ ⚙️ 🔍 📋 ⧉ ⋯ ⭐ 📁 🔗 ↺ ⛶ 📤) restent devant le mot,
  à la même place ; `scripts/i18n-check.js` refuse une traduction qui les perd.
- Guillemets de chaque langue : en “…”, de „…“, pl „…”, nl ‘…’, es / it / pt «…» (sans espaces).
- Touches : on écrit la touche Mac (« ⌘S ») ; elle est redessinée pour l’ordinateur (K12).
- Les nombres et les dates passent par `fmtNumber` / `fmtDate` ; jamais « 1 234 » écrit à la main dans une traduction.

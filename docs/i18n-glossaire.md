# 🌐 Glossaire commun des traductions

À suivre pour toute traduction de LCNDA (mode d’emploi : `docs/I18N.md`). Un mot de l’app se traduit **toujours de la
même façon** dans une langue. Ton : on tutoie partout (en : *you* ; es : *tú* ; de : *du* ; it : *tu* ; pt : *tu* ;
pl : *ty* ; nl : *je* ; cs : *ty* ; sv : *du* ; da : *du*). Phrases courtes et simples, comme en français.
Le tchèque, le suédois et le danois, puis le slovaque et le norvégien bokmål (et les langues suivantes, jusqu’au vietnamien et à l’indonésien) ont leur propre section à la fin (« Langues ajoutées ensuite »).

## Règles de forme

- Les symboles de tête validés (K11 : ＋ ↶ ↷ ⤒ ⤓ 💾 🖨 ✎ 🗑 × ↗ ⚙️ 🔍 📋 ⧉ ⋯ ⭐ 📁 🔗 ↺ ⛶ 📤) restent devant le mot,
  à la même place ; `scripts/i18n-check.js` refuse une traduction qui les perd.
- Guillemets de chaque langue : en “…”, de „…“, pl „…”, nl ‘…’, es / it / pt «…» (sans espaces).
- Touches : on écrit la touche Mac (« ⌘S ») ; elle est redessinée pour l’ordinateur (K12).
- Les nombres et les dates passent par `fmtNumber` / `fmtDate` ; jamais « 1 234 » écrit à la main dans une traduction.

## Langue ajoutée ensuite : turc (tr)

Fichiers à part : `assets/i18n/src/nord8/<zone>.tsv` (1re ligne `fr ¦ tr`, même clé que `<zone>.tsv`).
On traduit **depuis le français** (`node scripts/i18n-todo.js tr <zone>` montre l’anglais et l’allemand en aide ; aucune langue
proche n’est encore traduite).
Ton : on tutoie (*sen*), phrases courtes et simples : impératif 2e personne du singulier (« Seç », « Tıkla », « Sürükle »,
« Yeniden dene », « Yazımı kontrol et ») ; boutons et entrées de menu à l’impératif aussi (« Kaydet », « Sil », « Ekle »,
« Kapat »). Guillemets “…”. Lettres propres au turc (ç, ğ, ı, İ, ö, ş, ü) : toujours écrites ; la recherche de la FAQ les
ramène à c, g, i, i, o, s, u. **i / İ et ı / I sont deux lettres différentes** : « İptal », « İçe aktar » (İ avec point),
« Kapat », « Sınıf » (ı sans point) ; ne jamais mettre en capitales un texte turc avec `toUpperCase()` (« i » → « I » faux) ;
les noms de personnes, eux, gardent toujours les capitales françaises (`toLocaleUpperCase('fr-FR')`).
**Pluriels — ordre des formes dans les `.tsv`** : `one|other` (`FORMS.def` dans `scripts/i18n-build.js`) : 1 → « one »,
tout le reste (0, 2, 21, 1,5…) → « other ». Après un nombre, le nom turc reste au singulier (« 1 kişi », « 5 kişi ») :
les deux formes sont donc presque toujours les mêmes (`kişi|kişi`, `gün|gün`, `hafta|hafta`), comme en hongrois.
**Suffixes après une variable** : le turc colle la fin du mot (génitif, locatif, accusatif…) et l’accorde au mot (harmonie
vocalique, « {name}’in » / « {name}’ın » / « {name}’un »…) ; on ne peut pas la deviner pour un `{x}` inconnu. On tourne
donc la phrase : la variable après deux-points (« Kişi: {name} », « Bilgi: {x} », « ⤒ İçe aktar: {what} »), ou devant
un mot entier qui ne s’accorde pas (« {what} bulundu », « {what} içe aktarıldı », « “{q}” için … »).
Années : « 1582’de » seulement pour un nombre écrit dans le texte, jamais après `{y}` (« {y} yılında ») ; siècles :
« 18. yüzyıl ». Pourcentage : le signe devant (« %{n} »). Les exemples de dates d’actes restent en français, lisibles par la
lecture C4 (« 12/03/1790 », « 12 mars 1790 », « 9 novembre 1799 »), jamais un mois turc. Les mots des actes cités (« à l’heure

## Langue ajoutée ensuite : indonésien (id)

Mêmes fichiers que le vietnamien : `assets/i18n/src/nord11/<zone>.tsv`, 3e colonne. `node scripts/i18n-todo.js id <zone>`
montre l’anglais et l’allemand. Bahasa Indonesia standard (EYD), ton simple et chaleureux : on dit **kamu**, jamais *Anda*
(choisi pour toute l’app, comme le tutoiement français) ; possessif collé « -mu » (« silsilahmu », « fotomu ») ; consignes
à l’impératif (« Pilih… », « Ketik… », « Coba lagi ») ; boutons à l’impératif (« Simpan », « Hapus », « Tambah », « Tutup »,
« Batal », « Ubah »). Guillemets **“…”**. Pas d’espace avant « : » ni « ? ». Exemples de dates d’actes en français ;
nombres avec la virgule décimale (`id-ID` : « 3,5 ») ; dates et nombres `id-ID`, sinon `en` (`intlFallback`).
**Pluriel : une seule forme** (`FORMS.id = ['other']`) : après un nombre, le nom ne se redouble pas (« 1 orang », « 5 orang »,
jamais « 5 orang-orang ») ; dans les `.tsv`, une seule valeur **sans « | »**. Le redoublement (« orang-orang », « berkas-berkas »)
reste possible dans une phrase sans nombre.
**Attention, `id`** : c’est aussi le nom d’une propriété dans tout le code (identifiant d’une fiche, d’un média…). Le code
de langue n’apparaît que dans les tables de langues (`LANGS`, `I18N_LANGS`, `FORMS.id`, `NAMES.id`, `FAQ_STEM.id`…), jamais
comme propriété d’un objet de données ; `tests/test-i18n-nord11.js` le vérifie.
